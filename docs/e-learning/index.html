Course handbook

SDD with SPECTRA

A tool-neutral methodology for keeping AI-generated code aligned with intent, anchored to SPECTRA for the hands-on labs. Designed for engineers who already write code daily and have at least passing exposure to AI coding agents.

Total time 9 hours
Pace Self-paced or 2-day workshop
Format 7 modules + 2 labs
SPECTRA and Spec Kit.SPECTRA is built on top of GitHub Spec Kit — it does not replace it. Spec Kit provides the core spec-driven loop this course teaches (specify → plan → tasks → implement); SPECTRA installs that loop for you with one command and adds agents for the work surrounding the code — requirements, architecture decisions, quality gates, and delivery. So learning SDD with SPECTRA means you are genuinely learning Spec Kit: the four-phase vocabulary, the artifacts, and the slash commands are all Spec Kit's, and everything in this course transfers to a plain Spec Kit project. SPECTRA is built and maintained by TELUS Digital — see the SPECTRA landing page for the full picture.

Suggested learning paths

Self-paced (recommended)
One or two modules per week over 4–5 weeks. Gives time for the labs to settle and for discussion prompts to land in real team contexts.
Two-day workshop
Day 1 covers Modules 1–3 (foundations + greenfield lab); day 2 covers Modules 4–7 (brownfield lab + practice + team aspects + AI-DLC).
Engineering-leadership track
Modules 1, 5, 6, and AI-DLC only. Skips the labs but covers everything needed to sponsor adoption — including how the lifecycle itself changes.
Hands-on track
Modules 2, 3, 4 only. For engineers who want to feel the practice before reading about it.

Lab codebase

Both labs use the same stack — Next.js 14 + React 18 + TypeScript + Tailwind CSS + localStorage — so what you learn in Module 3 transfers directly to Module 4.

  • Module 3 (greenfield) scaffolds a fresh Next.js project with create-next-app and uses SPECTRA to build a small to-do app from scratch. No Git, everything local.
  • Module 4 (brownfield) uses a starter codebase shipped with the course — a minimal but fully working to-do app. It supports add, mark-done, and delete, but has no specs and no due-date feature, mirroring the kind of codebase teams typically inherit. Module 4 walks through using the brownfield workflow to add a “due date” feature on top of it. The codebase ships without that feature on purpose.

The lab codebase ships as lab-codebase.zip. The download link is on the Module 4 page. Unzip it once and run npm install && npm run dev to get started.

Prerequisites

  • Working knowledge of JavaScript / TypeScript and React
  • Familiarity with the command line
  • Access to an AI coding agent — Claude Code (recommended), GitHub Copilot, Cursor, or similar
  • Node.js 18+ for running both labs
  • uv and Git for installing SPECTRA (uv manages Python for you — you don't write Python in either lab)
